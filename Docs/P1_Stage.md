# [전투 기획서] 스테이지 플레이 루프

## 11. 스테이지 구조 및 전투 루프

### 11.1 스테이지 진입 및 타임리밋

- **진입 흐름**: 마을 ➔ 스테이지 활성화 기믹 상호작용 ➔ 스테이지 로딩 및 진입.
- **소요 시간 및 타임리밋**: 1회 플레이는 **5분(300초)** 이내 종료되도록 구성. 제한 시간 초과 시 **미션 실패**로 처리되며 마을로 강제 퇴장.

### 11.2 스테이지 이관 및 성장 규칙

- **인벤토리 이원화**: 마을 인벤토리와 스테이지 인벤토리가 완전히 분리 운영. 스테이지 인벤토리는 모든 플레이어가 공유한다.
- **아이템 반출 규칙**: 스테이지 종료 시 **성공/실패 여부와 관계없이** 스테이지 내 획득 아이템 중 **최대 10개**를 선택하여 마을 인벤토리로 가져올 수 있다.
- **재화(돈) 획득 규칙**: "작은 동전 주머니", "큰 동전 주머니" 같은 아이템을 선택해 마을 인벤토리로 재화를 반출할 수 있다. 또는, 판매용 아이템 (예. 사이버 금괴)을 마을의 상인에게 판매할 수 있다.
- **EP 및 경험치 초기화**:
  * 스테이지 퇴장 시 누적된 모든 **EP(감정 점수)는 0점으로 초기화**.
  * 캐릭터 Level 및 경험치(EXP) 개념은 존재하지 않는다 (오직 에이전트 합성을 통한 스탯 증가와 장착한 스킬 빌드로 성장).

### 11.3 적대 에이전트 등급별 생성 스펙

`AgentInfo.json` 기준 스탯, 크기, 스킬이 필드 스폰 시 난수로 결정된다.

| 에이전트 등급 | 스탯 적용 비율 | 크기(Scale) 적용 비율 | 부여 스킬 및 패시브 규칙 |
| :--- | :--- | :--- | :--- |
| **약한 에이전트** | 50% ~ 70% (랜덤) | 50% ~ 70% (랜덤) | 보유 액티브 1개 + 패시브 1개 (랜덤) |
| **중간급 에이전트** | 70% ~ 90% (랜덤) | 70% ~ 90% (랜덤) | 보유 액티브 2개 + 패시브 2개 (랜덤) |
| **보스급 에이전트** | 100% ~ 120% (랜덤) | 100% ~ 120% (랜덤) | 보유 액티브 2개 + 패시브 2개 (랜덤) |

### 11.4 사이클(Cycle) 및 웨이브 진행 메커니즘

- **순차 웨이브 스폰**: 필드 상에는 최대 동시 존재 수(예: 10~15마리)를 유지하며, 처치될 때마다 순차적으로 보충 스폰된다.
- **1차 사이클**: 약한 적 20~22마리 순차 처치 ➔ 기믹`<인지 과부하 노드 LV1>` 등장 및 파괴.
- **2차 사이클**: 중간급 적 20~22마리 순차 처치 ➔ 기믹`<인지 과부하 노드 LV2>` 등장 및 파괴.
  * *기믹 스탯*: LV1 노드 대비 체력, 물리/감정 방어력, 데미지 캡 **최소 1.5배** 상승.
- **3차 사이클**: 보스급 1체 + 중간급 4체 + 일반급 6체 (총 11체) 순차 처치 ➔ 기믹`<인지 과부하 노드 LV3>` 등장 및 파괴 ➔ 최종 클리어.
  * *기믹 스탯*: LV1 노드 대비 체력, 물리/감정 방어력, 데미지 캡 **최소 2.25배** 상승.

### 11.5 <인지 과부하 노드 (Cognitive Overdrive Node)> 기믹 및 보상 규칙  
<img width="400" height="164" alt="Image" src="https://github.com/user-attachments/assets/36163135-d4e7-4672-9e27-386ddb883c94" />

- **오브젝트 성격**: 공격 및 이동을 하지 않는 Static 기믹 오브젝트.
- **보유 스탯**: `MaxHealth`, `PhysicsDefense`, `EmoDefense`, `DamageCap`
- **데미지 캡 및 방어 연산 로직**:
  * 단일 타격 피해(Hit Damage)가 `DamageCap` 이하인 경우 ➔ **데미지 무효화 (0 피해)**
  * 단일 타격 피해가 `DamageCap`을 초과하는 경우 ➔ 초과분에 한하여 방어율을 연산해 최종 체력 차감한다.
  $$\text{유효 피해량} = (\text{단발 타격 데미지} - \text{DamageCap}) \times (1 - \text{방어율})$$
- **기믹 파괴 보상 (Highest Damage Emotion EP Reward)**:
  * 인지 과부하 노드에게 피격 데미지가 들어오는 시점에, 주변 플레이어들에게 그 피격 데미지에 해당하는 감정 속성의 **EP 400점**을 주변 플레이어들에게 즉시 지급한다 (SphereTrace 사용).
  * 인지 과부하 노드가 파괴되는 시점에, 해당 노드에 **누적 피해를 가장 많이 입힌 감정 속성**을 실시간 연산한다.
  * 가장 높은 피해를 준 감정 속성의 **EP 2000점**을 주변 플레이어에게 즉시 지급(SphereTrace 사용).

### 11.6 <감정 여과 노드 (Emotion Filter Node, EFN)> 기믹 및 수확 규칙

- **컨셉 및 설정**: 에이전트들의 감정 폭주로 오염된 MageNet 심층 구역을 정화하기 위해 플레이어가 지참하는 오염 감정 여과 장치.
- **노드 마운트 ("씨뿌리기")**:
  * 플레이어는 스테이지 진입 시 **3개의 감정 여과 노드**를 보유한다.
  * 스테이지 상에 미리 지정된 노드 마운트 지점(Node Mount Spot)에서 원하는 감정 속성을 선택하여 설치한다.
  * 노드 마운트 실행 시마다 **30초의 재사용 대기시간**이 적용된다.
- **데이터 정화 및 자동 수확 ("수확")**:
  * **여과 수치 축적**: 설치된 감정 여과 노드의 감지 범위 내에서 적 에이전트들에게 가한 데미지만큼 여과 수치가 1:1로 실시간 축적된다.
  * **2,000점 완충 수확**: 여과 수치가 **2,000 데미지**에 도달하면 즉시 자동 수확이 발동하여 해당 노드 속성의 **EP 2,000점**을 **전역(Global) 모든 플레이어**에게 지급하고 소멸한다.
  * **피격 리스크**: 없음 (적 에이전트의 공격에 의해 수치가 차감되거나 파괴되지 않음).
- **인지 과부하 노드 생성 시 강제 수확 메카닉**:
  * 각 사이클 조건 달성으로 `<인지 과부하 노드>`가 스폰되는 순간, 필드에 설치되어 있던 모든 감정 여과 노드는 **현재까지 축적된 여과 수치만큼 즉시 자동 수확**되어 전역 플레이어에게 EP를 지급한 후 소멸한다.
  * *예시: 2,000점을 다 채우지 못하고 1,700점이 누적된 상태에서 인지 과부하 노드가 등장하면, 즉시 1,700 EP를 지급하고 소멸.*
- **스테이지 잔존 규칙**: 다음 스테이지로 이관되지 않으며, 해당 스테이지 종료 시 모든 노드 및 설치 상태는 초기화된다.

## 12. `StageInfo.json` 데이터 테이블 구조 정의

**AgentKey 뒤에 _N이라 적혀있으면 N마리 소환한다는 의미**

```json
{
    "Name": "TUTORIAL_0",
    "StageDisplayName": "제1 인지 방역 구역 (웨이브 2개)",
    "MapName": "L_Tutorial_0",
    "LimitTime": 300,
    "MaxActiveAgents": 1,
    "Waves": [
      {
        "SpawnType": "FIXED",
        "TotalCount": 2,
        "AgentList": ["Longneck_1", "InsangA_1"],
        "StageGoalKey": "GIMMICK_NODE_LV1"
      },
      {
        "SpawnType": "FIXED",
        "TotalCount": 2,
        "AgentList": ["Longneck_1", "InsangB_1"],
        "StageGoalKey": "GIMMICK_NODE_LV2"
      }
    ],
    "ClearRewardKey": "REWARD_STAGE_01"
}
```

## 13. `SequenceInfo.json` 데이터 테이블 구조 정의  
후보 스테이지들(CandidateStageKeys) 중에서 조건에 따라(선행 퀘스트, 날씨, 게임 세계관 속의 여론) 혹은 랜덤으로 스테이지를 선택함  
```json
[
  {
    "Name": "SEQ_CHAPTER_01",
    "SequenceDisplayName": "제 1 인지 방역 구역 조사",
    "StagePools": [
      {
        "StageIndex": 1,
        "CandidateStageKeys": ["DEATH_00","DEATH_01"]
      },
      {
        "StageIndex": 2,
        "CandidateStageKeys": ["STEAMPUNK_00","DEATH_04"]
      }
    ]
  }
]
```
