# [기획서] 융합(합성) 시스템 규격서

## 1. 개요
본 문서는 보유 중인 에이전트(몬스터), 스킬카드, 아이템 중 3종을 조합하여 새로운 에이전트, 스킬카드, 아이템을 생성하는 **융합(합성) 시스템**의 상세 기획, 스탯 보너스 계산 로직 및 실시간 파형(오실로스코프) 연출 규격을 정의한다.

---

## 2. 융합 시스템 기본 메커니즘

### 2.1 융합 재료 및 결과
* **재료 구성**: 플레이어가 보유한 **[에이전트], [스킬카드], [아이템]** 중 총 **3개**를 자유롭게 선택
* **융합 결과**: 재료의 조합에 따라 **[에이전트], [스킬카드], [아이템]** 중 1종 결과물 창조
* **조합 관리**: 모든 조합 레시피 및 결과 데이터는 `FusionInfo_Result.json` (`FusionInfo_Recipe`) 테이블로 관리

### 2.2 에이전트 융합 시 세부 변화
융합 결과물이 **에이전트**인 경우 아래 규칙이 적용된다.
1. **신규 에이전트 탄생**: 조합 공식에 따른 새로운 에이전트 생성
2. **스킬 계승**: 재료 에이전트에 장착되어 있던 스킬 및 재료 스킬카드 중 **최대 3개 스킬 계승**
3. **스탯 변화 (스킬 기반 보너스)**:
   * **스킬 스크랩**: 융합 재료 에이전트들의 장착 스킬 + 재료로 사용된 스킬카드 각각의 스킬 수집
   * **스탯 합산**: 수집된 스킬들의 카테고리를 분류하고, 카테고리별 부여 스탯을 최종 에이전트에 스탯 보너스로 합산 적용

## 4. 융합 재화 및 비용 산정 규칙

### 4.1 기본 규격
* 융합은 횟수 제한 없이 **무제한** 시도 가능
* 융합 실행 버튼 클릭 시 재화(골드) 차감

### 4.2 비용 산정 방식
* **산정 기준 ($X$)**: 융합 재료에 에이전트가 포함된 경우, 해당 에이전트들의 누적 합성 횟수 중 **가장 높은 합성 횟수**를 $X$로 지정한다. (에이전트 미포함 시 $X = 0$)
* **비용 계산식**:
  $$\text{비용} = \text{기본비용} \times (X + 1)^{1.5}$$

### 5.1 연출 개요 및 레이어 구조
재료 투입 단계에 따라 재료 고유의 **감정 주파수, 감정 상성, 후보 레시피 힌트, 최종 결과물 신호**를 3중 사인파 합성 오실로스코프 머티리얼(`Base`, `Detail`, `Variation`)로 시각화한다.

* **3중 파형 레이어 구성**:
  * **Base (기본 파형)**: 주 파동(가장 낮은 주파수 재료) 또는 3슬롯 충족 시 예상 결과물의 고유 파형
  * **Detail (세부 파형)**: 2번째 재료 간섭 파형 또는 특수 스킬/부산물의 배음 레이어
  * **Variation (변조 파형)**: 2슬롯 투입 시 후보 레시피의 비어 있는 3번째 재료 주파수를 예고하는 튜너 잔물결 레이어
* **파형 정규화 (클리핑 방지)**: 여러 파형이 중첩될 때 이론상 최대 합성 높이가 위젯 상하 허용 범위(`MaxVisualWaveAmplitude = 0.36`, UV 중심 `0.5` 기준)를 초과하면, 파형 비율과 색상 가중치는 유지한 채 전체 진폭만 동일 비율로 축소하여 화면 잘림을 방지한다.
* **이동 속도 보정**: 고주파 파형의 윤곽이 과도한 회전 속도에 뭉개지지 않도록 주파수 제곱근 비례 속도($\text{Speed} = \text{BaseFactor} \times (0.6 + 0.4\sqrt{\text{Frequency}})$)를 적용한다.

### 5.2 8대 감정 속성별 기본 파형 프리셋 (`ItemSignalInfo`)
모든 에이전트, 스킬카드, 아이템은 `ItemSignalInfo` 테이블에 정의된 주 감정(`PrimaryEmotion`), 부 감정(`SecondaryEmotion`), 희귀도(`Rarity` 1~5)에 따라 고유 파형 파라미터를 갖는다.

| 감정 속성 (`EEmotionType`) | 기본 강도 (`Strength`) | 기본 진폭 (`Amplitude`) | 주파수 (`Frequency`) | 초기 위상 (`Phase`) | 중심 색상 (`CoreColor`) | 발광 색상 (`GlowColor`) |
| :--- | :---: | :---: | :---: | :---: | :--- | :--- |
| **Joy (기쁨)** | 1.00 | 0.20 | 4.0 | 0.00 | 황금색 `(1.00, 0.84, 0.00)` | 주황빛 `(1.00, 0.55, 0.00)` |
| **Sadness (슬픔)** | 1.00 | 0.26 | 1.0 | 0.00 | 청색 `(0.12, 0.56, 1.00)` | 심해색 `(0.05, 0.20, 0.80)` |
| **Anger (분노)** | 1.15 | 0.22 | 8.0 | 0.00 | 적색 `(1.00, 0.14, 0.00)` | 화염색 `(1.00, 0.40, 0.00)` |
| **Fear (공포)** | 0.95 | 0.16 | 12.0 | 0.25 | 보라색 `(0.54, 0.17, 0.89)` | 암자색 `(0.30, 0.05, 0.60)` |
| **Trust (신뢰)** | 1.00 | 0.20 | 2.0 | 0.00 | 에메랄드 `(0.00, 0.98, 0.60)` | 청록색 `(0.00, 0.70, 0.45)` |
| **Disgust (혐오)** | 1.00 | 0.18 | 3.5 | 0.50 | 올리브 `(0.60, 0.80, 0.20)` | 이끼색 `(0.35, 0.55, 0.05)` |
| **Anticipation (기대)** | 1.00 | 0.19 | 3.0 | 0.15 | 주황색 `(1.00, 0.55, 0.00)` | 황토색 `(1.00, 0.80, 0.20)` |
| **Surprise (놀람)** | 1.10 | 0.24 | 10.0 | 0.33 | 시안 `(0.00, 1.00, 1.00)` | 하늘색 `(0.50, 0.90, 1.00)` |

* **복합 감정 보정**: `SecondaryEmotion`이 지정된 경우 외곽 발광(`GlowColor`)을 부 감정의 중심색으로 치환하고 위상을 `+0.25` 이동시킨다.
* **희귀도 강도 보정**: 등급(`Rarity` 1~5)에 따라 기본 강도(`Strength`)에 $0.82 + (\text{Rarity} \times 0.10)$ 배율을 곱한다.

### 5.3 투입 단계별 파형 변화 시퀀스

#### 1) 0슬롯 (초기 대기 상태)
* `Base`, `Detail`, `Variation` 3개 레이어의 강도가 모두 `0`으로 소거된 초기 상태를 유지한다.

#### 2) 1슬롯 투입 (단일 신호 활성화)
* 투입된 1번 재료의 고유 파형이 `Base` 레이어에 활성화되며, 나머지 레이어는 비활성 상태를 유지한다.

#### 3) 2슬롯 투입 (감정 상성 간섭 + 3번째 필요 재료 튜너 잔물결)
2번째 재료가 투입되면 **두 재료의 고유 주파수는 보존**한 채 아래 두 가지 연출이 동시에 작동한다.

* **[A] 8대 감정환 상성 물리 간섭 (`Base` + `Detail` 레이어)**
  플루치크 8대 감정환(`Joy - Trust - Fear - Surprise - Sadness - Disgust - Anger - Anticipation`) 상의 최단 거리(0~4)를 계산해 두 파형의 간섭 형태를 변화시킨다.
  * **거리 0 (동일 감정 — 보강 간섭)**: 두 파형의 위상을 완전 동기화(`Phase` 일치)하고 강도·발광을 증폭하여 굵고 흔들림 없는 정상파를 형성한다.
  * **거리 1 (인접 감정 — 조화 맞물림)**: 1/4 주기(`+0.25`) 위상차를 두고 두 감정의 발광 색상을 부드럽게 그라데이션 융합한다.
  * **거리 2~3 (교차 감정 — 완만한 중첩)**: `+0.15` 위상차와 약한 진폭 맥놀이(`0.18`)가 섞인 이중 파형을 형성한다.
  * **거리 4 (대립 감정 — 상쇄/충돌 간섭, 예: 기쁨↔슬픔, 분노↔공포)**: 반주기(`+0.50`) 위상 반전과 함께 서로의 중심 색상을 외곽 발광으로 교차시키는 강렬한 보색 대비를 이루며, `Detail` 파형이 주기적으로 수축·팽창하는 강한 맥놀이 진동(`0.50`)이 발생한다.
* **[B] 3번째 필요 재료 주파수 튜너 (`Variation` 레이어)**
  현재 2개 재료를 포함하는 3재료 레시피(`A + B + ?`)를 검색하여, **아직 비어 있는 3번째 슬롯에 요구되는 재료의 고유 주파수와 감정 색상을 옅은 잔물결(`Strength 0.85`, `Amplitude 0.14`)로 파형 표면에 중첩**시킨다. (와일드카드 조건인 경우 백청색 고주파 잔물결 표시, 유효 레시피가 없으면 비활성화)

#### 4) 3슬롯 투입 (예상 결과물 파형으로 전환)
3개 슬롯이 모두 채워지면 레시피 매칭 결과(`Result.Key`)의 `ItemSignalInfo`를 조회하여 **결과물 고유의 파형(`Base`)**으로 즉시 전환된다.

| 결과물 유형 | 파형 레이어 및 시각 연출 규칙 |
| :--- | :--- |
| **일반 결과물** | 결과물 고유 단일 파형(`Base`)으로 수렴 (`Detail`, `Variation` 소거) |
| **특수 스킬 보유 / 조건부 각성** | 결과물 `Base` 파형 위에 `4배음` 고주파 빛무리(`Detail`, HDR 발광)를 한 겹 추가 |
| **Rarity 5 (초희귀 결과물)** | 중심 코어 색상이 백금 HDR 발광 `(2.6, 2.4, 1.9)`으로 승격 |
| **복제체(`_Replica`) / 부산물(`Garbage`, `IncompleteBirth`)** | 색상 명도 감쇠(`×0.65`) + `2.37배` 비정수 불협화 잔떨림(`Detail`) 추가로 불안정한 실패 신호 표현 |

#### 5) 최종 합성 확정 (`StartWaveFusionAnimation`)
* 합성 실행 버튼 클릭 시 `Detail`과 `Variation` 레이어가 완전히 소거(`Strength -> 0`)되며 최종 결과물의 단일 코어 파형으로 수렴한다. 수렴 애니메이션 종료 시 완료 이벤트(`FusionAnimaComplete`)를 호출한다.

### 5.4 파형 물리 지표 기반 스탯 보너스 연동
합성된 파형 곡선(64구간 샘플링)으로부터 산출된 3가지 물리 지표는 UI 프리뷰 및 서버 어빌리티 스탯 보정에 동일하게 사용된다.

* **PowerScore (위력 지표)**: 합성 파형의 최대 진폭($\text{MaxPeak} \times 1.5$) → 기본 위력 보너스 배율 (조건부 각성 레시피 달성 시 `×1.15` 추가 보정)
* **SharpnessScore (예리함 지표)**: 합성 파형의 최대 기울기($\text{MaxSlope} / 10.0$) → 치명타/관통 보너스 배율
* **StabilityScore (안정성 지표)**: 최저 주파수 대비 배음 정수비 오차(불협화도) 기반(`0.0 ~ 1.0`) → 조합 안정성 및 대성공 확률
