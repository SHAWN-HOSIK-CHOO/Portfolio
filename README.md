### MageNet (개발 중)  
<img width="400" height="210" alt="Image" src="https://github.com/user-attachments/assets/4bc2141d-2d70-4e4f-9630-457320f4aad6" />
<img width="400" height="210" alt="Image" src="https://github.com/user-attachments/assets/6bbb7c8a-3940-4369-858a-a09622bf9465" />  
  
- **한 줄 소개:** 약·강공 / 패링 / 액티브 슬롯의 자유로운 스킬 조합과 3체의 에이전트 융합을 통해 나만의 전투 스타일을 설계하는 3D 액션 RPG
- **장르 / 플랫폼:** 멀티플레이 3D 액션 RPG / PC (패드 지원)
- **사용 엔진:** Unreal Engine 5.6
- **개발 기간:** 2026.03 ~ 진행 중
- **개발 인원:** 2인
- **담당 역할:** 기획 / 프로그래밍 / 모델링
- **주요 특징:**
  - **자유도 높은 액션 & 무기 커스터마이징:** 약공격, 강공격, 패링, 액티브 슬롯에 원하는 스킬을 독립적으로 장착하고, 무기 고유 효과(슈퍼아머, 체력 회복, 대미지 배율 등)와 결합하여 자신만의 액션 시너지를 창출.
  - **에이전트 스탯 및 스킬 동기화:** 플레이어는 최대 3체의 에이전트를 장착할 수 있으며, 장착된 에이전트들의 평균 스탯과 보유 스킬(패시브/액티브)이 플레이어에게 그대로 동기화되어 전투에 적용됨.
  - **무한 융합(합성) 메커니즘:** 에이전트, 스킬 카드, 아이템을 자유롭게 합성하여 스탯을 강화하고 원하는 핵심 스킬을 계승시켜 최적화된 시너지 빌드를 완성할 수 있음.
  - **8대 감정 속성 & 지배적 감정 폭주:** 플루치크의 8대 감정(다단 히트, 필중, 치명타 등 고유 속성) 스킬을 활용하며, 폭주(LB+RB) 시 스킬들이 더 강력한 '혼합 감정 스킬'로 전이되어 스탯 증폭과 특수 효과(GE)를 발생시킴.
  - **서버 다이브(Dive) 세계관:** 우주 위성 서버에서 지상의 기계를 조종하는 AI 에이전트 본체를 소멸시키기 위해, 물리 연산이 적용된 3D 가상 서버 내부로 직접 침투(Dive)하는 판타지 세계관을 다룸.

- **한 줄 소개:** 스케이트보드를 타고 속도와 질량을 키워 상대를 격파하고 태그볼을 쟁탈하는 2인 실시간 멀티플레이 결투 게임
- **장르 / 플랫폼:** 2인 온라인 배틀 액션 / PC
- **사용 엔진 / 기술:** Unity 6, Unity Relay, Unity NGO
- **개발 인원:** 2인
- **담당 역할:** 게임 기획 / UI / 모델링 / 클라이언트 및 서버 프로그래밍
- **주요 특징:**
  - **속도 & 질량 기반 물리 충돌:** 더 빠르게, 더 무거운 상태에서 부딪힐수록 상대에게 강한 데미지와 먼 거리 넉백(Knockback) 부여
  - **전략적 아이템 파밍:** 필드 아이템을 획득해 질량 증가, 속도 증가, 체력 회복 등 능력을 강화하고 태그볼 수집
  - **태그볼 강탈:** 상대를 필드 밖으로 밀쳐내거나 체력을 0으로 만들면 상대가 가진 태그볼의 50%를 뺏어오는 역전 요소
  - **승리 조건:** 제한 시간 종료 시점 기준, 더 많은 태그볼을 소지한 플레이어가 최종 승리
  - **실시간 네트워크:** Unity Relay 및 Unity NGO 기반 2인 대전 환경 구축

- **장르 / 플랫폼:** VR 체험 시뮬레이션 / Meta Quest 2
